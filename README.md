# Duke3D-ART-Tools
Утилита для работы с .art файлами от игр на движке Build (Duke Nukem 3D)
* Распаковка .art файлов в сырой формат данный dat (каждый тайл в .dat) в папку (+ Создается файл .LST где находится подробная информация о тайлах)
* Упаковка в .art файл из .LST файла и с указанной папки
* Конвертор из .dat в .bmp и обратно из .bmp в .dat
